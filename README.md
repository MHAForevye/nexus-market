# Nexus Market bağlantı teşhis yaması

Bu yama Market API'sinin başarısız yanıtlarında JSON olmayan yanıtları ve endpoint bilgisini görünür kılar. API adresi, kart editörü, kart verileri, sunucu URL'leri veya bakiye işlemleri değiştirilmez.

## Uygulama
1. `nexus-market-main/js/api.js` ve `nexus-market-main/js/app.js` dosyalarını Market deposunda aynı yolların üzerine kopyalayın.
2. GitHub Pages'i yeniden yayınlayın.
3. Market'i yeniden açın. Hata oluşursa ekrandaki hata kodu ve endpoint ayrıntısını not edin/ekran görüntüsü gönderin.

Bu, canlı sunucudaki eksik endpoint/dağıtım/CORS sorunlarını tek başına çözmez; hatanın gerçek kaynağını daha açık gösterir. Sunucu URL'si ve kart editörü akışları değiştirilmemiştir.
